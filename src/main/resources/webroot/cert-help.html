Install the ttDrop certificate

One-time step per device. Afterwards this server — and every future ttDrop session from the same computer — opens without warnings, and the page can be installed as an app.

First download the certificate: ttdrop-ca.crt. Then follow your platform below. The certificate is generated on the computer running ttDrop and never leaves your network; it can only vouch for that computer's own ttDrop servers.

Check the fingerprint first. The ttDrop window on the host computer shows the certificate's SHA-256 fingerprint. This page received:

If the two differ, do not install it — someone on the network may be impersonating the server. Trusting a certificate authority lasts until you remove it, so it is worth the ten seconds.

iPhone / iPad (iOS, iPadOS)

  1. Download ttdrop-ca.crt in Safari and tap Allow when asked to download a configuration profile.
  2. Open Settings — a Profile Downloaded entry appears near the top. Tap it and tap Install.
  3. Then go to Settings → General → About → Certificate Trust Settings and switch on full trust for ttDrop CA.
  4. Reload the ttDrop page.

Android

  1. Download ttdrop-ca.crt.
  2. Open Settings → Security & privacy → More security settings → Encryption & credentials → Install a certificate → CA certificate (wording varies by vendor).
  3. Choose Install anyway and pick the downloaded file.
  4. Reload the ttDrop page.

Windows

  1. Download ttdrop-ca.crt and open it.
  2. Click Install Certificate…, choose Local Machine (or Current User).
  3. Select Place all certificates in the following store → Trusted Root Certification Authorities → finish.
  4. Restart the browser.

macOS

  1. Download ttdrop-ca.crt and open it — Keychain Access imports it.
  2. In Keychain Access, find ttDrop CA (System or login keychain), open it, expand Trust, and set When using this certificate to Always Trust.
  3. Restart the browser.

Linux

  1. System-wide (Debian/Ubuntu): sudo cp ttdrop-ca.crt /usr/local/share/ca-certificates/ && sudo update-ca-certificates (Fedora: /etc/pki/ca-trust/source/anchors/ + update-ca-trust).
  2. Chromium and Firefox keep their own store — import via the browser's Settings → Privacy/Security → Certificates → Import, trusting it for websites.
  3. Restart the browser.

To undo, remove "ttDrop CA" from the same certificate store. If the server's certificate ever stops matching (for example the computer's address changed), delete keystore.p12 in the server's ~/.config/ttdrop/ — a fresh certificate is issued from the same CA, so devices stay trusted.
